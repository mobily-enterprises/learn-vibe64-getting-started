# Introduction to using Vibe64

Topic 0.4.3 is a Learning v2 release of the introduction, for someone
with no coding experience. Each lesson is a list of short steps the learner can
read on their own in the Learning environment (**L**). In Lesson 0 the yellow
step bar plays each step as short guided beats that point at the real screen
and notice what the learner does. **Teach me** asks Colleague to explain the
current step on the real screens; **Show me** points at or opens the place a
step talks about (or replays a step's beats). Steps pass only through automatic
checks, choice questions, an AI review of the learner's work against the
step's rubric, or the learner's own **Done**; Colleague never grades.

| Code | Lesson | Outcome | Steps |
| --- | --- | --- | --- |
| V64-START-00 | Introduction to Vibe64 | Find every part of the project page and the Lesson pane; ask the coding chat for a tiny change, try it in Preview, find it in Dashboard and save it; meet Colleague; use Courses and **L**; know where AI setup lives. | 16, all with beats (3 choice, 6 self required; the coding-chat step, the AI-reviewed check step and the Save step are optional so the lesson still works if the AI stops answering) |
| V64-START-01 | Your first steps in Vibe64 | Press the real button and see a server's reply; know who to ask for help or a change and how to check and report a result. | 7 (1 auto, 3 choice required) |
| V64-START-02 | Make your first change | Edit `greeting(count)` in Dashboard → Files so the greeting counts presses, see it in Preview and pass the behaviour check. | 8 (1 auto code check, 1 choice, 1 self required) |
| V64-START-03 | Build with a database | Add a note in a real SQLite notes app, find it in Dashboard → Database, read the ERD, ask for a small feature and try it. | 8 (2 choice, 3 self required) |

Every lesson prepares its own disposable practice project from a bundled
exercise: the tour page (Lesson 0), the orientation app, the greeting app and
the notes app. Lessons 2 and 3 require Lesson 1. Lesson 1 does not require the
introduction; its welcome points back to it.
