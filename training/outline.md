# Introduction to using Vibe64

Preview 0.1.3 contains one complete introduction, for someone with no coding experience. Allow about 10–15 minutes. There are no topic prerequisites; the person must be signed in and permitted to use the prepared practice project.

| Code | Lesson | Outcome | Status |
| --- | --- | --- | --- |
| V64-START-01 | Your first steps in Vibe64 | Find the workspace, ask for help or a change, try the real application in Preview, report what happened, and return to the same Colleague conversation. | Published in preview |

Colleague prepares a disposable practice project using the existing orientation application. The learner presses its real button and reads its response. Afterwards, Colleague controls an SVG to illustrate that action, adjusting the explanation to the conversation. Three short questions are answered in chat; three practical checks require the learner's actual application actions.

The introduction ends with a useful habit: ask for help or a change, try the result in Preview, then say what you tried, what happened and what you expected. This is the complete curriculum for this preview. No further lesson is promised. Release and pilot acceptance remain separate from this source's published lesson status.
