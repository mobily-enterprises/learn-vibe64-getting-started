# Getting started and creating your first application

Preview 0.1.0 for a person with no computing experience. No topic prerequisites. The first useful outcome is navigating an actual workspace and explaining a real browser request and server response. The eventual outcome is asking for, trying, improving, saving and reopening a small checklist application.

Only lesson 01 is complete teaching content. Lessons 02–12 are draft planning material and cannot be taught or counted as a completed course. Publication follows pilot acceptance and review of each lesson.

| Order | Code | Lesson | Practical outcome | Status |
| --- | --- | --- | --- | --- |
| 01 | V64-START-01 | Find your way around the workspace | Locate the project, Colleague, coding conversation and Preview; explain a request and response. | Published in preview |
| 02 | V64-START-02 | Know who does what | Route three example requests to Colleague, the coding assistant or the running application. | Draft: not teachable |
| 03 | V64-START-03 | Describe the application you want | Describe audience, task and the observable outcome you want. | Draft: not teachable |
| 04 | V64-START-04 | Start a training project and session | Use the approved training flow and enter the correct session. | Draft: not teachable |
| 05 | V64-START-05 | Ask for a first working application | Ask the coding assistant for a small checklist application. | Draft: not teachable |
| 06 | V64-START-06 | Use Preview to try the application | Try adding and completing a checklist item in the real application. | Draft: not teachable |
| 07 | V64-START-07 | Compare the result with your request | Report a reproducible mismatch between requested and actual behaviour. | Draft: not teachable |
| 08 | V64-START-08 | Request a precise improvement | Request one precise improvement while retaining the checklist behaviour. | Draft: not teachable |
| 09 | V64-START-09 | Understand what changed | Explain the purpose of one visible change and verify its effect. | Draft: not teachable |
| 10 | V64-START-10 | Save your work | Use the actual Save control and interpret its result. | Draft: not teachable |
| 11 | V64-START-11 | Leave and return | Reopen the same checklist project/session and recover your task. | Draft: not teachable |
| 12 | V64-START-12 | Build a small variation independently | Build a modest checklist variation and explain it independently. | Draft: not teachable |

Each lesson after 01 requires completion of the preceding lesson. Lesson 01 uses a prepared orientation exercise. Lesson 04 will teach the restricted creation flow. Lessons 05–12 create then continue one retained checklist exercise sequence, with no database and no change of domain. Discarding that exercise preserves conceptual passes but does not recreate practical evidence.
