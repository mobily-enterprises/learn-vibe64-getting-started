## Public contract

The browser button posts its fresh interaction reference. The server creates a request reference, records at most 64 responses and sends a greeting. The page displays the actual response. Failed requests show retry guidance. An optional parent-bound channel exposes bounded observations; the application never grades or authenticates learners. Restart loses observations. When a response shows a changed server instance, the old page closes its observation channel and requires Reload preview before a new press. Response-display observations are fenced to the exact request and render revision; the host separately verifies Preview visibility.
