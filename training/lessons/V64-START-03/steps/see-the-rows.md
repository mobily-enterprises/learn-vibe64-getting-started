Now look inside the database. Press **Show me** to open **Dashboard →
Database**, then **Data**.

A database keeps data in **tables**, a bit like spreadsheets. This app has two:

- `notebooks`: one row for each notebook, such as Home and Work.
- `notes`: one row for each note.

Open the `notes` table and find the note you just added. Each column holds one
piece of information about the note: its title, when it was created, and which
notebook it belongs to.

Press **Done** when you've found your note.
