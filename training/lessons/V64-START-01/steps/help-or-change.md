There are two kinds of things you'll ask for:

- **Help**, like “Where do I try the app?” Colleague can answer that, and can
  open the right screen for you.
- **A change**, like “Please change the greeting to Welcome.” A coding agent
  makes changes to the application. You can ask the coding agent yourself in
  the coding chat, or ask Colleague to pass the request on.

Talking about an idea doesn't change the application by itself. And Preview
is the application, not a chat: typing into it won't change how it works.
