Now try the real application.

1. Open **Preview** (press **Show me** if you're not sure where it is).
2. Press the **Ask the server** button.
3. Read the message that appears.

The page briefly says “Asking the server…” and then shows
**Hello from the server!** with a request reference underneath. You don't need
to remember the reference.

When your press goes through, this step checks it for you. If it doesn't
update, press **Check now**.

**If something goes wrong:** if the button stays greyed out and the page asks
you to reload, use **Reload preview** and press the button again. If the app
doesn't start at all, **Restart preview** starts it again. Problems like this
are never your fault.
