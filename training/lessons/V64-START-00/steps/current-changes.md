**Current changes**, another Dashboard tool, lists the files that changed
since your project was last saved and shows exactly what changed.

If you asked the agent for a change, `public/index.html` is listed here with
the old and the new lines. If you skipped that step, the list is empty.

```beats
do changes: Open Dashboard → Current changes.
show changes: The agent's edit shows here: the old lines and the new ones. Nothing here yet? Then nothing changed.
```
