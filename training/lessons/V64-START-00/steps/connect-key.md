Now put the key into Vibe64.

1. Open **AI Accounts**. Where it is depends on how you use Vibe64:
   - **On your own computer:** press the person button in the header to open
     **Account settings**, then choose the **AI Accounts** tab.
   - **On Vibe64 Online:** open **AI Accounts** in Management.

   Ask Colleague to open it for you if you can't find it.
2. Choose **Connect regular Z.AI API**. If you don't see that button, choose
   **Add connection**, then **Choose provider** on the **OpenCode** card,
   search for “Z.AI” and pick the regular **Z.AI** row, not **Z.AI Coding
   Plan**.
3. Paste your key into the **API key** field. It is masked, so the key stays
   hidden.
4. Press **Verify and connect**. In the first-time setup, the button is called
   **Verify key and start Vibe64**.

Vibe64 sends a tiny test request to make sure the key works, then saves the
connection. If you see an error, read it, fix what it says and press the
button again. Never paste the key into a chat to get help: describe the error
instead.

On a phone the setup can fill the screen; scroll to find the same controls.

Press **Done** when the connection is saved.
