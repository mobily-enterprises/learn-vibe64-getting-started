This step happens on Z.AI's website, not in Vibe64.

1. Open [Z.AI's API key page](https://z.ai/manage-apikey/apikey-list). If
   you're in Vibe64's first-time setup, the **Create a regular Z.AI API key**
   button opens the same page.
2. Register or sign in, and complete any verification Z.AI asks for.
3. Create an API key and keep the page open, or copy the key somewhere
   private for a moment.

[Z.AI's getting-started guide](https://docs.z.ai/guides/overview/quick-start)
explains each screen. You don't have to buy anything to create a key.

Press **Done** when you have your key.
