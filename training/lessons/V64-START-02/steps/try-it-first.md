Open **Preview** and press **Ask the server** two or three times.

The page shows **Hello from the server!** every time. Underneath, a line
counts your presses, for example “The server has counted 3 presses so far.”

So the server knows how many times you've pressed the button, but the greeting
never mentions it. In the next steps, you'll change that.

Press **Done** when you've tried it.
