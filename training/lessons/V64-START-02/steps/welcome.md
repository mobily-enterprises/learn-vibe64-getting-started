Last time you pressed a button and a server sent back a greeting. This time
you'll change what the server says, with your own hands.

You'll edit one small file, see your change in Preview, and then let Vibe64
check your code. It takes about 12 minutes. This is a fresh practice project
made for this lesson, so a mistake can't break anything that matters, and you
don't need to know how to code.

Press **Teach me** whenever you'd like Colleague to explain a step.
