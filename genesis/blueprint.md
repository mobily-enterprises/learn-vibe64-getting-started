# Blueprint

Help a complete beginner use Vibe64 through a short, hands-on introduction:
tour the project page, ask the coding chat for a tiny change, try it in
Preview, find it in Dashboard and save it; try a real application; change a
small function themselves; and see where an application keeps the data it
saves.

Topic 0.3.1 uses Learning v2 lessons. Every lesson is an ordered list of short
steps whose learner-facing text is readable without AI. Colleague is the
teacher: it follows the current step, explains it using the lesson's teaching
notes, opens real screens, points at declared guide places and replays the
client-server SVG. Colleague never judges. A step passes only through a
declared automatic check with learner-origin evidence, a choice question
compared on the server, or the learner's own **Done**.

Lesson 0 (Introduction to Vibe64) is a tour of the editor with a minimal
static page: the project page, the Lesson pane, Preview, the coding chat,
Dashboard, Save and Git log, Colleague, Courses and **L**. Its coding-chat
steps are optional so it can be finished without a connected AI; it only says
where AI setup lives and does not teach it. Every lesson prepares a disposable
practice project from a bundled exercise: the tour page, the orientation app,
the editable greeting app and the SQLite notes app.

This repository owns the step text, teaching notes, exercises, checks, SVG and
its finite-state controller. Public Vibe64 and Online own installed content,
the Learning environment, Colleague, progress, practice projects and access;
validating content does not prove the native lesson experience. Earlier 0.1.x
releases keep their installed pins and learner history.
