# Blueprint

Help a complete beginner find their way around Vibe64 and eventually build, try, improve, save and reopen a small checklist application. This topic preview has one complete lesson and eleven explicitly incomplete drafts. The first useful outcome is navigating the real workspace and explaining an observed browser/server request and response. Teaching uses Colleague and real managed exercises; diagrams only explain. No learner progress or hosted access implementation belongs to this content repository.
