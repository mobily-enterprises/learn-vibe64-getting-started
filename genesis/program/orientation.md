## Public contract

The button posts an interaction reference to a real server, which prepares a greeting and request reference. The browser displays the response. At most 64 ephemeral records permit the pinned finite check to verify exact identities. In V64-START-01 it is the `try-the-app` step's automatic check; host context and channel correlation of the learner's own press remain required for a pass. A changed server instance requires Reload preview and a fresh host channel before another press. Display observations match the exact request, render revision and displayed reference; host foreground visibility remains separate. The exercise has its own portable Genesis setup/output contracts and no external dependencies.
